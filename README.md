# Бот @bahbenzin_bot — развёртывание на Render (бесплатно)

Бот показывает цены на топливо в Уфе: меню заправок → бренд, адрес, цены на
АИ-92/95/98/100 и дизель. Данные собраны с benzonavt.ru (файл `stations.json`).

Версия для Render работает через **webhook**: Telegram сам обращается к боту,
поэтому он работает 24/7, даже когда ваш ПК выключен. Бесплатный тариф Render
засыпает после ~15 минут без активности и «просыпается» по первому сообщению
(холодный старт ~1 минута) — это нормально для бесплатного хостинга.

---

## Шаг 1. Загрузите файлы на GitHub

1. Заведите аккаунт на https://github.com (бесплатно, карта не нужна).
2. Создайте новый публичный репозиторий: **New repository** → имя
   `bahbenzin-bot` → **Create repository**.
3. Нажмите **Add file → Upload files** и загрузите **все** файлы из этой папки:
   - `app.py`
   - `stations.json`
   - `requirements.txt`
   - `render.yaml`
   - `README.md`
4. Внизу нажмите **Commit changes**.

> Если есть git — можно через него: `git init`, `git add .`, `git commit`,
> `git remote add origin https://github.com/ВАШ_ЛОГИН/bahbenzin-bot.git`,
> `git push -u origin main`.

## Шаг 2. Подключите репозиторий к Render

1. Зайдите на https://render.com и зарегистрируйтесь (через GitHub, бесплатно).
2. Нажмите **New → Blueprint**.
3. Выберите ваш репозиторий `bahbenzin-bot`.
4. Render прочитает `render.yaml` и предложит создать сервис `bahbenzin-bot`
   (план **Free**). Нажмите **Apply**.
5. Дождитесь деплоя (несколько минут). В логах появится
   `Webhook установлен: https://...onrender.com/webhook`.

Готово — бот работает в облаке.

## Шаг 3. Остановите локального бота

Как только на Render появился `Webhook установлен`, локального бота нужно
остановить, иначе он конфликтует с webhook.

В PowerShell:
```powershell
Stop-Process -Name python -Force
```

## Проверка

Отправьте боту `/fuel` (или слово `cjj`) — появится меню заправок.
Выберите заправку — увидите бренд, адрес и цены.

## Обновление цен

Данные в `stations.json` — снимок с benzonavt.ru. Чтобы обновить цены,
перескачайте страницы (скрипты `scrape_stations2.py` + `clean_data3.py`
в основной папке), замените `stations.json` и закоммитьте изменения в GitHub —
Render передеплоит автоматически.

## Опционально: чтобы бот не «засыпал»

Бесплатный Render засыпает без активности. Можно держать его «тёплым»
бесплатным монитором (например, UptimeRobot): добавьте монитор с URL
`https://ВАШ_СЕРВИС.onrender.com/` и интервалом 5 минут. Тогда бот будет
отвечать мгновенно, без холодного старта.
